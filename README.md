# paper-briefing-web

Published output of a private daily economics research digest.

This repository holds **only rendered HTML**. The harvester, source registry,
research-interest profile and dedup state live in a separate private
repository and are never published here.

Pages are served with `noindex, nofollow, noarchive, nosnippet` and a
`robots.txt` of `Disallow: /`, which keeps them out of search results. They are
still readable by anyone who has the URL.
